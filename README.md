# Swan releases

Download **SwanSetup.exe** from the [latest release](https://github.com/NOLANTHEBEAST/Swan-releases/releases/latest)
to install Swan, the premium Gorilla Tag client for Windows. It installs for your Windows user (no admin needed)
and keeps itself up to date.

This repository only holds the published builds and the update feed Swan checks
(`releases/latest/download/manifest.json`). Release notes are on each release.
